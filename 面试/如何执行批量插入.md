在 MyBatis 中执行批量插入可以通过多种方式实现，以下是 **3 种常用方法**及其适用场景和示例：

---

### **一、使用 `<foreach>` 动态 SQL 拼接**
#### **核心思路**  
通过动态 SQL 的 `<foreach>` 标签，将多条插入语句合并为单条 SQL，利用 `INSERT INTO ... VALUES (...), (...), ...` 语法一次性插入。

#### **步骤**
1. **Mapper 接口**  
   ```java
   public interface UserMapper {
       void batchInsertUsers(@Param("users") List<User> users);
   }
   ```

2. **Mapper XML**  
   ```xml
   <insert id="batchInsertUsers">
       INSERT INTO users (name, email)
       VALUES 
       <foreach item="user" collection="users" separator=",">
           (#{user.name}, #{user.email})
       </foreach>
   </insert>
   ```

3. **Service 调用**  
   ```java
   @Service
   public class UserService {
       @Autowired
       private UserMapper userMapper;
       
       @Transactional
       public void insertUsers(List<User> users) {
           userMapper.batchInsertUsers(users);
       }
   }
   ```

#### **特点**  
- **优点**：单次 SQL 请求，性能高。  
- **缺点**：  
  - 数据量过大时可能超出数据库 `max_allowed_packet` 限制（需分批次插入）。  
  - 不适用所有数据库（如 Oracle 需使用 `INSERT ALL` 语法）。

---

### **二、使用 `BATCH` 执行器（推荐）**
#### **核心思路**  
通过 MyBatis 的 `SqlSession` 切换到 `BATCH` 模式，将多次插入操作合并为批量提交。

#### **步骤**
1. **Mapper 接口**  
   ```java
   public interface UserMapper {
       void insertUser(User user);
   }
   ```

2. **Mapper XML**  
   ```xml
   <insert id="insertUser">
       INSERT INTO users (name, email)
       VALUES (#{name}, #{email})
   </insert>
   ```

3. **Service 调用（手动提交）**  
   ```java
   @Service
   public class UserService {
       @Autowired
       private SqlSessionFactory sqlSessionFactory;
       
       public void batchInsertUsers(List<User> users) {
           try (SqlSession sqlSession = sqlSessionFactory.openSession(ExecutorType.BATCH)) {
               UserMapper mapper = sqlSession.getMapper(UserMapper.class);
               for (User user : users) {
                   mapper.insertUser(user);
               }
               sqlSession.commit(); // 手动提交
           }
       }
   }
   ```

#### **特点**  
- **优点**：  
  - 自动合并 JDBC 批处理请求，减少网络 I/O。  
  - 兼容所有数据库。  
- **缺点**：需手动管理 `SqlSession` 和事务。

---

### **三、结合 JDBC `addBatch()` 方法**
#### **核心思路**  
直接通过 MyBatis 获取 JDBC 原生 `Connection`，手动控制批处理。

#### **步骤**
1. **Service 实现**  
   ```java
   @Service
   public class UserService {
       @Autowired
       private DataSource dataSource;
       
       public void batchInsertUsers(List<User> users) throws SQLException {
           String sql = "INSERT INTO users (name, email) VALUES (?, ?)";
           try (Connection conn = dataSource.getConnection();
                PreparedStatement ps = conn.prepareStatement(sql)) {
               for (User user : users) {
                   ps.setString(1, user.getName());
                   ps.setString(2, user.getEmail());
                   ps.addBatch();
               }
               ps.executeBatch(); // 批量执行
           }
       }
   }
   ```

#### **特点**  
- **优点**：直接控制底层 JDBC，灵活性高。  
- **缺点**：需手动处理资源释放和异常，代码侵入性强。

---

### **四、性能对比与选择建议**
| **方法**               | **性能** | **适用场景**                          | **注意事项**                     |
|------------------------|---------|-------------------------------------|--------------------------------|
| **`<foreach>` 动态 SQL** | 高      | 数据量适中（单次插入 1000 条以内）         | 避免 SQL 过长导致数据库拒绝         |
| **`BATCH` 执行器**      | 中      | 大数据量（万级以上）、需事务控制              | 确保在事务内提交                   |
| **JDBC `addBatch()`**  | 中高    | 需要直接控制底层 JDBC 或复杂批处理逻辑         | 需手动管理连接和异常                |

---

### **五、最佳实践**
1. **分批次插入**  
   大数据量时拆分列表，避免单次 SQL 过长或内存溢出：
   ```java
   List<List<User>> batches = Lists.partition(users, 1000); // 每批 1000 条
   batches.forEach(batch -> userService.insertUsers(batch));
   ```

2. **事务控制**  
   确保批量插入在事务中完成，避免部分失败导致数据不一致：
   ```java
   @Transactional
   public void insertUsers(List<User> users) {
       // 插入逻辑
   }
   ```

3. **主键处理**  
   若需返回自增主键，需配置 `useGeneratedKeys` 和 `keyProperty`：
   ```xml
   <insert id="insertUser" useGeneratedKeys="true" keyProperty="id">
       INSERT INTO users (name, email) VALUES (#{name}, #{email})
   </insert>
   ```

---

### **六、常见问题**
#### **Q1：`BATCH` 模式插入速度慢？**
- **原因**：未正确提交事务或未设置 `rewriteBatchedStatements=true`（MySQL 优化批处理）。  
- **解决**：  
  - MySQL JDBC URL 添加参数：`jdbc:mysql://...?rewriteBatchedStatements=true`  
  - 确保 `sqlSession.commit()` 在循环后执行。

#### **Q2：动态 SQL 插入报错“SQL 语法错误”？**
- **原因**：`<foreach>` 生成的 SQL 包含尾部逗号（空列表时）。  
- **解决**：添加 `<if test="list != null and !list.isEmpty()">` 包裹 SQL。

---

通过以上方法，可高效实现 MyBatis 批量插入，根据数据量和场景选择最优方案。
