在 JVM 中，引用类型（Reference Types）主要指的是与垃圾回收（GC）机制相关的对象引用分类，用于控制对象的生命周期和垃圾回收策略。Java 提供了 **4 种引用类型**，根据对象可达性和回收优先级的不同进行划分：

---

### **JVM 引用类型及区别**

| 引用类型      | 回收条件                   | 典型应用场景                     | 示例代码                          |
|---------------|---------------------------|----------------------------------|-----------------------------------|
| **强引用**    | 对象可达时**永不回收**     | 常规对象引用                     | `Object obj = new Object();`      |
| **软引用**    | **内存不足时**触发回收     | 缓存（如图片缓存）               | `SoftReference<Object> softRef = new SoftReference<>(obj);` |
| **弱引用**    | **GC 运行时立即回收**      | 临时缓存、避免内存泄漏（如 WeakHashMap） | `WeakReference<Object> weakRef = new WeakReference<>(obj);` |
| **虚引用**    | **对象回收时**触发通知     | 资源清理跟踪（如堆外内存释放）   | `PhantomReference<Object> phantomRef = new PhantomReference<>(obj, queue);` |

---

### **详细说明**

#### 1. **强引用（Strong Reference）**
- **核心特性**：  
  - 最常见的引用类型，通过 `new` 关键字创建的对象默认是强引用。  
  - 只要强引用存在，对象**永远不会被垃圾回收**，即使内存不足时 JVM 会抛出 `OutOfMemoryError` 而不是回收强引用对象。  
- **使用场景**：  
  - 常规对象引用，如 `String str = "Hello";`。  

#### 2. **软引用（Soft Reference）**
- **核心特性**：  
  - 内存充足时，软引用对象不会被回收；  
  - 内存不足时（接近 `OutOfMemoryError`），JVM 会回收软引用对象。  
- **使用场景**：  
  - 缓存敏感数据（如图片缓存），允许在内存紧张时释放资源。  
- **示例**：  
  ```java
  // 创建软引用
  SoftReference<byte[]> softCache = new SoftReference<>(new byte[1024 * 1024]);
  // 获取对象（可能返回 null）
  byte[] data = softCache.get();
  ```

#### 3. **弱引用（Weak Reference）**
- **核心特性**：  
  - 无论内存是否充足，只要发生垃圾回收，弱引用对象**立即被回收**。  
  - 需配合 `WeakHashMap` 使用，自动清理键值对。  

> [!question]
> [[为什么弱引用要配合WeakHashMap使用？]]

- **使用场景**：  
  - 临时缓存（如 ThreadLocal 的键），避免内存泄漏。  
- **示例**：  
  ```java
  // 创建弱引用
  WeakReference<Object> weakRef = new WeakReference<>(new Object());
  // 强制触发 GC
  System.gc();
  // 弱引用对象会被回收，get() 返回 null
  System.out.println(weakRef.get()); // 输出：null
  ```

#### 4. **虚引用（Phantom Reference）**
- **核心特性**：  
  - 虚引用对象**无法通过 get() 获取对象**（始终返回 `null`）。  
  - 唯一用途是跟踪对象被回收的通知（通过关联的 `ReferenceQueue`）。  
- **使用场景**：  
  - 管理堆外内存（如 DirectByteBuffer），确保资源释放。  
- **示例**：  
  ```java
  ReferenceQueue<Object> queue = new ReferenceQueue<>();
  PhantomReference<Object> phantomRef = new PhantomReference<>(new Object(), queue);
  // 对象回收后，虚引用会被加入队列
  System.gc();
  Reference<?> ref = queue.remove(); // 阻塞直到有引用入队
  ```

---

### **关键区别总结**
| 特性          | 强引用       | 软引用               | 弱引用          | 虚引用          |
|---------------|-------------|---------------------|----------------|-----------------|
| **回收时机**  | 永不回收     | 内存不足时回收       | GC 运行时回收   | 对象回收时通知   |
| **是否可获取对象** | 直接获取   | `get()` 可获取       | `get()` 可获取 | `get()` 返回 `null` |
| **典型用途**  | 常规对象     | 内存敏感缓存         | 临时缓存        | 资源清理跟踪     |

---

### **使用建议**
- **优先使用强引用**：除非有明确的内存管理需求。  
- **缓存优化**：  
  - 使用 `SoftReference` 实现内存敏感缓存（如图片缓存）。  
  - 使用 `WeakHashMap` 实现键为弱引用的缓存（避免内存泄漏）。  
- **资源管理**：  
  - 使用 `PhantomReference` 跟踪对象回收，确保释放堆外资源（如文件句柄、Native 内存）。
