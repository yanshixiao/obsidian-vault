### **TF-IDF（词频-逆文档频率）** 是衡量文本中词语重要性的经典方法，广泛应用于 **文本相似度计算、搜索引擎排序、关键词提取** 等场景。其核心思想是：**一个词语在文档中出现的频率越高，同时在所有文档中出现的频率越低，则该词语对当前文档的代表性越强**。

---

### **一、TF-IDF 的组成与计算**

#### **1. 词频（Term Frequency, TF）**
• **定义**：衡量一个词语在 **单个文档** 中的出现频率。  
• **计算公式**：  
  \[
  \text{TF}(t, d) = \frac{\text{词语 } t \text{ 在文档 } d \text{ 中的出现次数}}{\text{文档 } d \text{ 的总词数}}
  \]
• **作用**：高频词对文档内容贡献更大（如“机器学习”在技术文档中多次出现）。

#### **2. 逆文档频率（Inverse Document Frequency, IDF）**
• **定义**：衡量一个词语在 **整个语料库** 中的普遍重要性。  
• **计算公式**：  
  \[
  \text{IDF}(t) = \log\left(\frac{\text{语料库中文档总数}}{\text{包含词语 } t \text{ 的文档数} + 1}\right)
  \]
• **作用**：常见词（如“的”“是”）的IDF值低，专业术语（如“卷积神经网络”）的IDF值高。

#### **3. TF-IDF 综合权重**
\[
\text{TF-IDF}(t, d) = \text{TF}(t, d) \times \text{IDF}(t)
\]

---

### **二、文本相似度计算步骤**
1. **分词与预处理**：  
   • 对文档分词，去除停用词（如“的”“和”），统一大小写。
   • 示例：  
     ◦ 文档1：`机器学习 需要 大量 数据`  
     ◦ 文档2：`深度学习 依赖 大数据 和 算力`

2. **构建词袋模型（Bag of Words）**：  
   • 提取所有文档的词汇表，例如：  
     \[
     \{\text{机器学习, 数据, 深度学习, 依赖, 大数据, 算力}\}
     \]

3. **计算每个词语的 TF-IDF 值**：  
   • 假设语料库共有1000篇文档：  
     ◦ 词语“机器学习”出现在50篇文档中，则：  
       \[
       \text{IDF}(\text{机器学习}) = \log(1000 / (50 + 1)) \approx 3.0
       \]
     ◦ 文档1中“机器学习”出现1次，总词数4，则：  
       \[
       \text{TF}(\text{机器学习}, 文档1) = 1/4 = 0.25
       \]
     ◦ 最终：  
       \[
       \text{TF-IDF}(\text{机器学习}, 文档1) = 0.25 \times 3.0 = 0.75
       \]

4. **向量化表示文档**：  
   • 文档1的 TF-IDF 向量：`[0.75, 0.5, 0, 0, 0, 0]`  
     （对应词汇表：机器学习, 数据, 深度学习, 依赖, 大数据, 算力）  
   • 文档2的 TF-IDF 向量：`[0, 0, 1.2, 0.8, 1.5, 1.0]`

5. **计算余弦相似度**：  
   • 通过向量夹角余弦值衡量相似度：  
     \[
     \text{相似度} = \frac{\vec{A} \cdot \vec{B}}{\|\vec{A}\| \times \|\vec{B}\|}
     \]
   • 示例中两文档相似度较低（关键词不重叠）。

---

### **三、TF-IDF 的优缺点**

#### **优点**：
• **简单高效**：计算复杂度低，适合大规模文本处理。  
• **可解释性强**：直接反映词语对文档的重要性。  
• **灵活扩展**：可结合其他特征（如词性、位置）优化。

#### **缺点**：
• **忽略词序与语义**：将文本视为词袋，无法捕捉上下文关系。  
  （例如“苹果手机”和“手机苹果”会被视为相同）  
• **依赖语料库**：IDF需要全局统计，新增文档需重新计算。  
• **长文档偏差**：长文档中TF值易被稀释（可通过归一化缓解）。

---

### **四、实际应用场景**
1. **搜索引擎排序**：  
   • 计算查询词与网页的 TF-IDF 相似度，优先返回高权重文档。  
2. **推荐系统**：  
   • 基于用户浏览文档的 TF-IDF 向量，推荐相似内容。  
3. **文本聚类/分类**：  
   • 将文档表示为 TF-IDF 向量，使用 K-Means 或 SVM 进行聚类或分类。  
4. **关键词提取**：  
   • 选取 TF-IDF 值最高的词语作为关键词（如论文摘要生成）。

---

### **五、改进与替代方案**
1. **TF-IDF 变体**：  
   • **TF-IDF 平滑**：避免除零错误（如加1平滑）。  
   • **Sublinear TF**：对 TF 取对数（\(1 + \log(\text{TF})\)），抑制高频词影响。  
2. **词嵌入模型**：  
   • **Word2Vec / GloVe**：捕捉词语的语义关系。  
   • **BERT / Transformer**：基于上下文的动态向量表示。  
3. **混合模型**：  
   • 将 TF-IDF 与词嵌入结合，兼顾统计特征与语义信息。

### **六、代码示例（Python）**
```python
from sklearn.feature_extraction.text import TfidfVectorizer

# 文档集合
documents = [
    "机器学习需要大量数据",
    "深度学习依赖大数据和算力"
]

# 计算 TF-IDF 矩阵
vectorizer = TfidfVectorizer()
tfidf_matrix = vectorizer.fit_transform(documents)

# 输出词汇表与向量
print("词汇表:", vectorizer.get_feature_names_out())
print("TF-IDF 矩阵:\n", tfidf_matrix.toarray())

# 计算余弦相似度
from sklearn.metrics.pairwise import cosine_similarity
similarity = cosine_similarity(tfidf_matrix[0], tfidf_matrix[1])
print("相似度:", similarity[0][0])
```

输出示例：
```
词汇表: ['大量' '依赖' '和' '大数据' '学习' '算力' '数据' '机器' '深度' '深度机']
TF-IDF 矩阵: [[0.5, 0.0, 0.0, 0.0, 0.5, 0.0, 0.5, 0.5, 0.0, 0.0],
          [0.0, 0.4, 0.4, 0.4, 0.4, 0.4, 0.0, 0.0, 0.4, 0.4]]
相似度: 0.0
```

### **总结**
TF-IDF 通过量化词语的局部重要性和全局稀缺性，为文本相似度计算提供了基础但有效的工具。尽管存在局限性，它在工业界仍被广泛使用，尤其在资源受限或需要快速原型的场景中。对于更复杂的语义匹配需求，可结合深度学习模型进行增强。
