在 Java 中，确保三个线程 T1、T2、T3 按顺序执行的核心思路是通过同步机制控制它们的执行顺序。以下是几种实现方法及其详细说明：

---

### **方法 1：使用 `join()` 方法**
通过 `join()` 方法让主线程等待前一个线程完成后再启动下一个线程。

```java
public class JoinExample {
    public static void main(String[] args) throws InterruptedException {
        Thread t1 = new Thread(() -> System.out.println("T1"));
        Thread t2 = new Thread(() -> System.out.println("T2"));
        Thread t3 = new Thread(() -> System.out.println("T3"));

        t1.start();
        t1.join(); // 等待 T1 完成
        t2.start();
        t2.join(); // 等待 T2 完成
        t3.start();
        t3.join();
    }
}
```

**特点**：
- **简单直接**：通过主线程强制顺序执行。
- **缺点**：线程由主线程逐个启动，不符合“三个线程同时启动但自行协调”的场景。

---

### **方法 2：使用 `CountDownLatch`**
通过两个 `CountDownLatch` 控制线程的启动顺序，确保后一线程等待前一线程完成。

```java
public class CountDownLatchExample {
    public static void main(String[] args) {
        CountDownLatch latch1 = new CountDownLatch(1);
        CountDownLatch latch2 = new CountDownLatch(1);

        Thread t1 = new Thread(() -> {
            System.out.println("T1");
            latch1.countDown();
        });

        Thread t2 = new Thread(() -> {
            try {
                latch1.await(); // 等待 T1 完成
                System.out.println("T2");
                latch2.countDown();
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        });

        Thread t3 = new Thread(() -> {
            try {
                latch2.await(); // 等待 T2 完成
                System.out.println("T3");
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        });

        t1.start();
        t2.start();
        t3.start();
    }
}
```

**特点**：
- **线程同时启动**：三个线程在 `start()` 后同时进入就绪状态。
- **自动协调顺序**：通过 `await()` 和 `countDown()` 确保执行顺序。

---

### **方法 3：使用 `Semaphore`**
通过两个信号量控制线程的执行权限，确保后一线程必须等待前一线程释放许可。

```java
public class SemaphoreExample {
    public static void main(String[] args) {
        Semaphore s2 = new Semaphore(0);
        Semaphore s3 = new Semaphore(0);

        Thread t1 = new Thread(() -> {
            System.out.println("T1");
            s2.release(); // 允许 T2 执行
        });

        Thread t2 = new Thread(() -> {
            try {
                s2.acquire(); // 等待 T1 完成
                System.out.println("T2");
                s3.release(); // 允许 T3 执行
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        });

        Thread t3 = new Thread(() -> {
            try {
                s3.acquire(); // 等待 T2 完成
                System.out.println("T3");
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        });

        t1.start();
        t2.start();
        t3.start();
    }
}
```

**特点**：
- **灵活控制**：每个线程通过信号量独立控制执行权限。
- **无需主线程干预**：线程自行协调执行顺序。

### **方法 4：使用 `ReentrantLock` 和 `Condition`**
通过条件变量实现线程间的精准唤醒机制。

```java
public class ConditionExample {
    private static ReentrantLock lock = new ReentrantLock();
    private static Condition conditionT2 = lock.newCondition();
    private static Condition conditionT3 = lock.newCondition();
    private static volatile int state = 1; // 状态标识

    public static void main(String[] args) {
        Thread t1 = new Thread(() -> {
            lock.lock();
            try {
                System.out.println("T1");
                state = 2;
                conditionT2.signal(); // 唤醒 T2
            } finally {
                lock.unlock();
            }
        });

        Thread t2 = new Thread(() -> {
            lock.lock();
            try {
                while (state != 2) {
                    conditionT2.await(); // 等待 T1 完成
                }
                System.out.println("T2");
                state = 3;
                conditionT3.signal(); // 唤醒 T3
            } catch (InterruptedException e) {
                e.printStackTrace();
            } finally {
                lock.unlock();
            }
        });

        Thread t3 = new Thread(() -> {
            lock.lock();
            try {
                while (state != 3) {
                    conditionT3.await(); // 等待 T2 完成
                }
                System.out.println("T3");
            } catch (InterruptedException e) {
                e.printStackTrace();
            } finally {
                lock.unlock();
            }
        });

        t1.start();
        t2.start();
        t3.start();
    }
}
```

**特点**：
- **精准唤醒**：通过条件变量 (`Condition`) 实现线程间的精准通知。
- **灵活性高**：适合复杂同步场景，如多条件依赖。

### **方法 5：使用 `CompletableFuture`（Java 8+）**
通过链式调用 `thenRun()` 确保任务顺序执行。

```java
public class CompletableFutureExample {
    public static void main(String[] args) {
        CompletableFuture<Void> future = CompletableFuture.runAsync(() -> System.out.println("T1"))
                .thenRun(() -> System.out.println("T2"))
                .thenRun(() -> System.out.println("T3"));
        future.join(); // 等待所有任务完成
    }
}
```

**特点**：
- **简洁优雅**：函数式编程风格，代码简洁。
- **异步编排**：自动处理线程池和任务依赖。

### **总结**
| **方法**               | **适用场景**                           | **优点**                              | **缺点**                              |
|-----------------------|--------------------------------------|--------------------------------------|--------------------------------------|
| **`join()`**          | 简单顺序控制，主线程管理执行顺序          | 代码简单，无需额外同步工具              | 线程由主线程逐个启动，不符合并行启动场景 |
| **`CountDownLatch`**  | 线程同时启动，自行协调顺序               | 解耦线程间依赖，灵活控制                | 需要定义多个计数器                     |
| **`Semaphore`**       | 线程同时启动，按许可执行                 | 简单直观，资源控制灵活                  | 需要管理多个信号量                     |
| **`ReentrantLock`**   | 复杂同步逻辑，多条件依赖                 | 精准唤醒，灵活性高                     | 代码复杂度高，需手动释放锁              |
| **`CompletableFuture`**| Java 8+，链式任务编排                  | 函数式风格，简洁优雅                    | 依赖 Java 8+，不适用低版本              |

**最终建议**：  
- 若需简单顺序控制，优先选择 `join()` 或 `CountDownLatch`。
- 若需线程自行协调，选择 `Semaphore` 或 `ReentrantLock`。
